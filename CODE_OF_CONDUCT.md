# Code of conduct

Be decent. This project is for building a useful, auditable browser agent.

Expected:

- Assume good faith and argue about code, not people.
- Keep security reports private until a fix exists.
- Respect provider terms of service and website terms.
- Do not use Myna to spam, scrape at scale, bypass access controls, or harass.

Not acceptable:

- Harassment, threats, or discriminatory language.
- Publishing another person's keys, private data, or page content.
- Deliberately weakening the permission model or secret handling.
- Using the project to build malware or evade authentication.

Maintainers may remove comments, issues, or contributions that violate this.
