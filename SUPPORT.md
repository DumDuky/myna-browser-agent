## Questions and ideas

Use [GitHub Discussions](https://github.com/DumDuky/myna-browser-agent/discussions) for setup questions, provider advice, and workflow ideas.

## Bugs

Open a [bug report](https://github.com/DumDuky/myna-browser-agent/issues/new?template=bug_report.yml). Include the Myna version, Chrome version, OS, provider, permission mode, and clear reproduction steps. Redact keys, cookies, and private page content.

## Security

Do **not** open a public issue for a vulnerability. Use [private vulnerability reporting](https://github.com/DumDuky/myna-browser-agent/security/advisories/new) or the process in [SECURITY.md](../SECURITY.md).

## Provider and website problems

Myna talks directly to the provider and the page. If a provider rejects tools, streaming, images, or a model ID, start with the provider's own documentation. If a site blocks extension injection or requires a real file picker, check the limitations document before filing a bug.
