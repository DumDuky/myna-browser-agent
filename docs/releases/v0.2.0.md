# Myna v0.2.0

Myna is the open-source alternative to Claude in Chrome. It puts an AI browser agent in your side panel, uses your own API key, and keeps chats in your browser. No account, no backend, no telemetry.

## Highlights

- **One browser-wide chat.** The side panel follows the active tab; switching tabs no longer starts a separate conversation.
- **Bring your own provider.** Anthropic, OpenAI, OpenCode Go, Gemini, OpenRouter, Groq, DeepSeek, Mistral, xAI, Together, Fireworks, Azure, Ollama, LM Studio, or any OpenAI-compatible endpoint.
- **OpenCode Go presets.** Both the OpenAI-compatible and Anthropic Messages endpoints, with a per-conversation `x-opencode-session` header.
- **Permission presets.** Locked down, Ask first, Plan first, and Autopilot, with per-site rules preserved.
- **Appearance presets.** Follow system, Paper, Midnight, and Compact.
- **On-page agent motion.** Cursor, click ripples, typing caret, keycaps, scroll hints, and element flashes.
- **Remote MCP tools** over Streamable HTTP.
- **Scheduled tasks** with a visible runner window, saved results, and notifications.
- **File uploads, web fetch/search, and GIF export.**
- **Protected-page recovery.** Myna can open a normal tab when Chrome blocks the current page.

## Install

1. Download `myna-browser-agent-0.2.0.zip` from the release assets.
2. Extract it.
3. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
4. Select the extracted `myna-browser-agent-0.2.0` folder.
5. Pin Myna, open a normal website, and connect a provider in Settings.

Chrome/Chromium 116+ is required.

## Notes

- This is a beta. Interfaces and model presets may change.
- Myna is an independent clean-room implementation. It is not affiliated with Anthropic, Google, OpenAI, or any provider named in the project.
- API keys are stored locally. Use session-only keys or a low-limit provider key if that matters to you.
- Full limitations: https://github.com/DumDuky/myna-browser-agent/blob/main/docs/limitations.md
