Myna

An open-source browser agent with your own keys.

Myna is an independent, clean-room implementation inspired by the convenience of AI side panels. It is not affiliated with or endorsed by Anthropic. No analytics, no relay server, no account.

What leaves your browser?

Only the conversation and page context you send to your chosen provider. Myna has no backend. API keys are stored in Chrome local storage unless you choose session-only keys. Chats are stored in Chrome local storage.

Limitations

Myna is a local BYOK browser agent, not a full clone of Claude in Chrome or Claude Code. The complete list lives in docs/limitations.md.

  • Remote MCP over Streamable HTTP only; no stdio, legacy SSE, or OAuth.
  • No Claude Desktop pairing, native messaging, relayed inference, or Claude Code integration.
  • Scheduled tasks need Chrome running; file uploads use synthetic DataTransfer; GIFs cap at 40 frames.
  • No licensed search index, memory, projects, or multi-agent orchestration.
  • No cross-origin iframe or closed-shadow-root control.
